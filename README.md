# StudyFlow

**StudyFlow** — Windows-приложение для студентов и преподавателей: расписание в системном трее, быстрый просмотр пар, история занятий, заметки, изменения расписания, календарь учебных дней и кастомная тема.

## Возможности

- расписание учебного заведения и выбранной группы;
- компактный виджет по **клику на значок StudyFlow в системном трее**;
- открытие полного приложения из виджета;
- автоматическое обновление расписания;
- история прошедших занятий с календарным режимом;
- заметки к каждой паре с локальным сохранением;
- напоминания за день до занятий, к которым добавлена заметка;
- красная отметка дней/занятий с актуальными заметками;
- поиск по расписанию только на вкладке «Расписание»;
- отображение федеральных праздников, выходных и переносов;
- темы Light, Dark, Cyberpunk и полностью настраиваемая Custom Theme;
- фон-изображение, корректные HSV-палитры, blur, затемнение, прозрачность карточек, скругления и Glass UI;
- история и заметки не сбрасываются при смене группы;
- источники расписания: ЧТОТиБ, ЗабГК, ЗабИЖТ, ЗабГУ, ЧГМА и ЧПТК;
- проверка новых версий через GitHub;
- запуск вместе с Windows и работа в системном трее.

## История и заметки

История занятий и заметки сохраняются локально в данных пользователя StudyFlow. Записи привязываются к выбранной группе/цели, поэтому при переключении группы старые данные не уничтожаются.

История доступна в виде календаря:

- переключение месяцев;
- выбор конкретной даты;
- отметки занятий, праздников и заметок;
- просмотр сохранённых занятий за выбранный день;
- редактирование заметки прямо из истории.

## Напоминания

Если к завтрашнему занятию добавлена заметка, StudyFlow один раз напоминает об этом за день до занятия. Такое занятие/дата выделяется красным цветом.

## Custom Theme

Конструктор позволяет менять:

- фон;
- поверхности;
- карточки;
- акцент;
- основной и вторичный текст;
- границы;
- навигацию;
- скругления;
- прозрачность карточек;
- затемнение фонового изображения;
- размытие;
- Glass UI;
- собственное фоновое изображение.

HSV-палитра использует стандартную геометрию: насыщенность слева направо, яркость сверху вниз.

## Системный трей

StudyFlow не открывает компактное окно при наведении. Виджет появляется **только после клика по значку приложения в системном трее**.

Из виджета можно:

- открыть полное приложение;
- закрыть виджет.

В контекстном меню трея остаются:

- открыть StudyFlow;
- обновить расписание;
- настройки;
- полностью выйти.

Кнопки «Свернуть» и «Быстрое окно» из верхней панели приложения удалены.
